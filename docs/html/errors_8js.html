Middleware para manejar errores en la aplicación.

Este middleware captura los errores que ocurren durante la ejecución de la aplicación, los registra en la consola y responde con un mensaje de error al cliente.

Parameters
{Object}err - El objeto de error que contiene información sobre el error ocurrido.
{Object}req - El objeto de solicitud de Express.
{Object}res - El objeto de respuesta de Express.
{Function}next - La función que pasa el control al siguiente middleware.
Returns
{void} - No devuelve nada, solo maneja el error y envía la respuesta.
