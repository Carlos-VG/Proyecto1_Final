Limpia los datos eliminando solo las columnas necesarias y opcionalmente procesa los datos con un script de Python.

@async @function cleanData

Parameters
{Object}data - Los datos a limpiar, que contienen objetos con campos a filtrar.
{Array<string>}columns - Las columnas que deben mantenerse en los objetos de datos.
{boolean}[usePython=false] - Si es verdadero, se ejecuta un script de Python para procesar los datos.
{string}[pythonScriptPath=''] - La ruta al script de Python que se debe ejecutar (si usePython es verdadero).
{Array}[filters=[]] - Filtros opcionales que se pasarán al script de Python (si usePython es verdadero).
Returns
{Promise<Object[]>} Los datos procesados, limpios y, si es necesario, filtrados por Python.
Exceptions
{Error}Lanza un error si algo falla al procesar los datos o ejecutar el script de Python.
