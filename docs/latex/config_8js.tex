\doxysubsection{Detailed Description}
Configuración de la aplicación y carga de variables de entorno. 

Este archivo carga las variables de entorno desde un archivo {\ttfamily .env} y configura los parámetros clave de la aplicación, como el puerto de la aplicación, la URL de acceso central, la versión de i\+Top y el secreto JWT para la autenticación.
